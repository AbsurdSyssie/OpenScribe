Quick action help

Create a quick action with AI

Quick actions give OpenScribe a reusable instruction for the current consultation—for example, producing a referral letter, a focused summary, or a patient message. If the existing actions do not fit your work, an AI assistant can help create one. You do not need to write any code.

Import adds quick actions from a JSON file or pasted text.

Export saves selected quick actions as a JSON file so you can keep or move them.

Do not include patient information, transcripts, clinical notes, credentials, or other confidential data.

How to create a quick action

  1. Select Copy instructions for AI. This copies everything the AI needs to create a quick action OpenScribe can understand.
  2. Open the AI assistant you normally use and paste the instructions.
  3. Describe what you want the action to produce, who it is for, its tone and format, and anything it must include or avoid. The AI will ask questions if anything is unclear.
  4. Copy all the finished JSON the AI returns. You do not need to understand or edit it.
  5. Return to OpenScribe, select Import, paste the JSON, then select Submit.
