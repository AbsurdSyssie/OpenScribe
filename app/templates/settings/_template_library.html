Template help

Create a template with AI

Templates tell OpenScribe how to organise and write your finished note. If the existing templates do not suit the way you work, an AI assistant can help you create one. You do not need to write any code.

Import adds a template to OpenScribe from a JSON file or pasted text.

Export saves selected templates as a JSON file so you can keep or move them.

Do not include patient information, transcripts, clinical notes, credentials, or other confidential data.

How to create a template

  1. Select Copy instructions for AI. This copies everything the AI needs to create a template OpenScribe can understand.
  2. Open the AI assistant you normally use and paste the instructions.
  3. Describe the note you want—for example, its purpose, headings, level of detail, and anything it should leave out. The AI will ask questions if anything is unclear.
  4. When the AI gives you the finished JSON, copy all of it. JSON is simply the specially formatted text OpenScribe needs—you do not need to understand or edit it.
  5. Return to OpenScribe, select Import, paste the JSON, then select Submit.
