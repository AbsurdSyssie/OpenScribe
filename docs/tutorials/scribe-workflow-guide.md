# Scribe Workflow Guide

The Scribe guide is the same for users and team leaders. A leader has more team controls, but the clinical workflow does not change.

## Start the guide

Select **Guide** at the bottom left of the Scribe workspace.

When a user has no consultation, OpenScribe creates one synthetic tutorial consultation. It contains:

- a sectioned template;
- a working note;
- a transcript;
- a saved dictation;
- a sectioned draft note;
- two draft follow-ups;
- one tutorial quick action.

The example contains no audio and no real patient data. It does not call a speech or writing service and does not use provider quota.

The guide:

- keeps the current control clear;
- blurs the rest of the page;
- shows one short instruction at a time;
- provides **Back**, **Next**, and **Close** buttons;
- opens the right Scribe tab for each step;
- shows the working note, transcript, dictation, note, and follow-ups in order;
- returns to the tab you started on when you close it.

You can start it again from **Guide** at any time. The tutorial consultation stays in **Recent consultations** until you delete it or retention removes it. The tutorial template and quick action stay in **My Library** until you delete them.

If the user already has consultations but none is open, the guide opens the most recent consultation. It does not add a tutorial consultation.

## Workflow

1. Create a new consultation.
2. Choose the note template.
3. Choose **Recorded upload**, then start the recording.
4. Add brief points to the working note during the consult.
5. Stop the recording when the consult ends.
6. Review the transcript.
7. Add and save a post-consultation dictation.
8. Check the template, then create the note.
9. Read and edit the whole draft.
10. Select or clear lines, move them, and copy a section or all selected lines.
11. Open **Follow Ups**.
12. Type or record extra context.
13. Choose a quick action when it helps, or leave it blank.
14. Generate the follow-up.
15. Select earlier results from **Recent**, change the request, and generate another version.

## Review the result

OpenScribe creates drafts. Check each note and follow-up before you copy or use it. Correct errors, missing facts, and text in the wrong section.
