## Severity Guide

| Severity | Meaning |
| --- | --- |
| Critical | Direct compromise of transcript-derived content, credentials, auth, or production infrastructure likely. |
| High | Practical bypass or exposure affecting protected data, role boundaries, provider secrets, or destructive actions. |
| Medium | Security control missing or incomplete with plausible exploit path but compensating controls exist. |
| Low | Hardening, evidence, or process gap with limited immediate exploitability. |
| Info | Documentation/evidence task only. |
