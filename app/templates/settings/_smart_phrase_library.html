Smart phrase help

Create a smart phrase with AI

Smart phrases insert reusable text when you type a slash and trigger, such as /FOLLOWUP, in the note editor. An AI assistant can help draft useful wording and package it for OpenScribe. You do not need to write any code.

Import adds your personal smart phrases from a JSON file or pasted text.

Export saves selected smart phrases as a JSON file so you can keep or move them.

Do not include patient information, transcripts, clinical notes, credentials, or other confidential data.

How to create a smart phrase

  1. Select Copy instructions for AI. This copies everything the AI needs to create smart phrases OpenScribe can understand.
  2. Open the AI assistant you normally use and paste the instructions.
  3. Describe the reusable text you need, when you use it, and any wording or placeholders it should contain. The AI will ask questions if anything is unclear.
  4. Copy all the finished JSON the AI returns. You do not need to understand or edit it.
  5. Return to OpenScribe, select Import, paste the JSON, then select Submit.
